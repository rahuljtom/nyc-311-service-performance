Case study · NYC 311 service requests · all of 2024

Where should New York put the next unit of housing-repair capacity?

3,456,770 requests from the city's 311 system, cleaned and analysed in SQL. The question: which requests wait longest to be closed, why, and where would effort recover the most?

Recommendation

Fix the process behind the five largest housing-maintenance complaint types (unsanitary condition, plumbing, paint/plaster, door/window, water leak). Do not spend the capacity on borough or ZIP targeting, or on changing how people contact 311.

  1. The housing agency (HPD) holds 40.8% of the 665,424 requests not closed within 7 days; those five types alone hold 29.0%.
  2. Complaint type alone explains 52% of whether a request is slow. Borough, ZIP code and month each explain 2.7% or less.
  3. A one-quarter cut in the slow rate of those five types recovers about 48,223 slow requests with 5 targets. Fixing every borough-and-type cell that is slower than chance recovers 27,520 but needs 118; the 25 worst ZIP-type cells recover only 2,586.
  4. Requests from more heat-vulnerable neighbourhoods show no consistent penalty: their slow rate differs from what their complaint mix predicts by at most 2.5 points, in both directions, and the gap does not grow with the index.

1 · The data had traps, and one of them changes who looks worst

311 data looks tidy but is not. Seven problems were found and handled before any number was trusted. The biggest: 27,563 requests are marked Closed with no close date, almost all from one agency (DHS). Counted as open they inflate the slow total, and DHS's slow rate would read 3.8 times too high. They are left out of every closure measure instead.

2 · Where the slow requests are

A request is slow if it was not closed within 7 days. Twelve complaint types hold about 51% of all slow requests; housing (orange) dominates.

Requests not closed within 7 days, top 12 agency and complaint-type pairs

Slow is not the same as failing: some types are slow by design (new tree requests, for-hire vehicle complaints), and only 0.6% of requests carry a due date, so fair per-type targets cannot be tested.

How long requests stay open (Kaplan–Meier, open requests treated as still waiting)

After 7 days 37% of HPD requests are still open; after 30 days 12%; after 89 days 3.6%. NYPD requests are closed within hours, so it is not comparable with the others (closure there generally means an officer responded).

3 · Why they are slow: the type of problem, not the place

Each bar predicts "slow or not" from one set of facts, using rates learned on half the requests and scored on the other half. If place mattered, geography would explain something.

Share of the variation in slow / not slow that each set of facts explains

Adding borough, channel and month to complaint type lifts the score from 52.3% to 55.9%. The 10.7% for place, channel and month without type is mostly intake channel standing in for complaint mix.

HPD: how long the five biggest slow types stay open

The five curves are close together: the slowness is shared across housing-repair types, which points to a common cause (how repairs are dispatched and verified) rather than five separate problems.

4 · What to do, and what each option would recover

Recoverable means slow requests above what the citywide rate for that complaint type predicts, minus a 95% chance margin, so noise in small cells is not counted as something to fix. Option C is a scenario (a quarter off the slow rate), not a forecast.

Slow requests recovered, and how many separate targets each option needs

Do more vulnerable neighbourhoods wait longer for the same help?

Gap = actual slow rate minus the rate expected from complaint type, with a 95% margin. Index 1 is least and 5 most vulnerable (NYC Health Department Heat Vulnerability Index, joined by ZIP). Gaps are small, point in both directions and do not rise with the index (the 95% margins are narrow, so the HPD index-2 gap of about +2.5 points is real but small), so this data gives no reason to target by neighbourhood. This is a statement about response times, not about need.

5 · What would change this recommendation

  • One year, one city. A second year would show whether the same types stay slow.
  • Closure is an agency decision. If HPD closes requests only when a landlord reports a fix, 7-day closure measures landlord behaviour, not the agency's. That would shift the fix from capacity to enforcement.
  • Due dates are almost absent (0.6% of requests), so there are no per-type targets to judge against.
  • Associations, not causes. The 25% cut is a scenario; the data cannot say it is achievable.
  • The dataset changes. Close dates keep arriving, so a later pull can differ slightly. These tables are from the pull dated 7 November 2026.
